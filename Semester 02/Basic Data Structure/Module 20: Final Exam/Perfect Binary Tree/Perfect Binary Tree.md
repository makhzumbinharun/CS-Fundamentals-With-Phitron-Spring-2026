# Perfect Binary Tree

## Problem Statement

You will be given a binary tree as input in level order. You need to tell if the binary tree is perfect or not.

A binary tree is called **perfect** if:

- Every internal node has exactly two children.
- All leaf nodes are at the same level.
- The tree is completely filled with no gaps.

A perfect binary tree follows this formula:

```text
Total number of nodes = 2^(depth + 1) - 1
